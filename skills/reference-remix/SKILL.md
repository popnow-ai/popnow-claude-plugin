# Reference remix

Formats are free to learn from; specific creative work is not free to copy. This skill extracts the structure of a reference and rebuilds it with the user's own content.

## Inputs

The user describes the reference or pastes its transcript, shot notes or timestamps. You cannot watch videos, so ask for a description if there is none. Then collect the user's product, characters, setting and goal.

## Step 1: Break down the reference

Produce a beat table:

| # | Time | Shot type and camera | What happens | Text / audio | Purpose |
|---|---|---|---|---|---|

Then summarize the format in 3 to 5 lines: hook type, pacing (cuts per second), story shape (problem-solution, transformation, list, reveal), emotional arc, and the call to action.

## Step 2: Rebuild it as original work

- Keep: structure, pacing, shot types, the kind of hook, the story shape.
- Replace: all characters, faces, voices, dialogue, music, logos, settings and distinctive visual signatures with the user's own or newly invented ones.
- Do not reproduce copyrighted characters, a creator's recognizable persona, a celebrity likeness, or lines of dialogue and lyrics from the reference.
- If the reference is the user's own past video, they can of course reuse more of it.

## Output

1. The beat table for the reference.
2. The format summary.
3. A new shot list for the user's version, in the `shot-list` format, with a continuity sheet.
4. A short note on what makes the new version different from the reference.

Hand off to `video-prompts`, `keyframe-prompts` and `generation-budget` as needed.
