# Image model reference

Options as offered by common hosting platforms in late October 2026. Check the platform you use for current limits.

| Model | Resolutions | Strengths | Watch out for |
|---|---|---|---|
| Nano Banana 2.1 (Google) | 1K, 2K, 4K; very wide aspect ratio range | Photorealism, edits that keep the original intact | Tends to translate or drop non-English text |
| Nano Banana Pro | 1K, 2K, 4K | Plans layout first: dense text, diagrams, title cards | Higher price per image |
| GPT Image 2.5 (OpenAI) | 1K, 2K, 4K; quality low to max | Clean, exact text including non-English; follows instructions closely | May add logos or insignia unprompted; check before commercial use |
| Seedream 5.0 Pro (ByteDance) | 1K, 1.5K, 2K | Rich detail, up to ten reference images, strong with Chinese cultural context | Max 2K |
| FLUX 2 Pro (Black Forest Labs) | 1K, 2K | Photoreal images, readable text, hex color control | Fewer aspect ratios than the others |

All of them support image-to-image editing. For a product, a reference photo plus an edit prompt beats a text-only prompt.
